# Cel stop-motion experiments

Generated hand-painted artwork, explicit character poses, deterministic staging, local musical scoring and HyperFrames assembly. This workflow is separate from the Deforum repaint studies.

- [Big Softie](projects/big-softie/README.md): a short about a puppy and a gentle Rottweiler, with reproducible tooling and review records.
- [Spider-Verse dinner montage](projects/spider-verse-dinner-montage/README.md): a measured study of the time-lapse montage in *Across the Spider-Verse*, and a plan to recreate its swapped paintings.

The follow-up [Side by Side clay dance study](../blender-animation/projects/clay-dance/README.md) tests native 3D puppets and authored foot contacts as another character-animation method.

All project media belongs inside its project folder and is preserved locally. Generated media and dependencies are ignored by Git.
