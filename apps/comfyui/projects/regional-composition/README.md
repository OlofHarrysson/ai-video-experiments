# Regional composition

Status: research and experiment proposal prepared 2026-09-10; not rendered.

Build images by assigning a full-canvas background prompt and separate foreground prompts to spatial regions. Start with rectangles; retain a path to painted masks and incremental object insertion. Use ComfyUI on RunPod independently of the Deforum animation experiments.

- [Research and recommendation](../../../../docs/research/regional-composition.md)
- [First experiment proposal](experiments/baseline.md)
- [Upstream workflow evidence](references/README.md)

The first model proposal is ordinary SDXL base 1.0, already used in this repository. This is a mechanism study, not a claim that SDXL is the best available image model. A modern-model follow-up should retain the same scene brief and spatial controls while adopting that model's native conditioning and sampling recipe.
