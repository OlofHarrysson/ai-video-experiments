# Render attempts

New runs are written here by `experiment.py run --project botanical-cathedral --experiment EXPERIMENT`. Write the experiment note first. Each unique run contains its exact graph, receipt, frames and preview.

All first-session runs remain in [the original archive](../../../outputs/) and are indexed by the [baseline experiment](../experiments/baseline.md). No run was moved or removed.

Keep every attempt. Record reviews and useful ranges in experiment notes; never replace a run with a newer generation. These media folders are ignored by Git. See the [working convention](../../../../../docs/workflow.md).
