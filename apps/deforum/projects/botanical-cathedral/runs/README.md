# Render attempts

All six first-session attempts and future renders belong here. The [baseline experiment](../experiments/baseline.md) indexes their purpose and findings; the [session report](../experiments/baseline-results.md) records execution and cost.

New runs are written by `experiment.py run --project botanical-cathedral --experiment EXPERIMENT`. Write the experiment note first. Each unique run contains its exact graph, receipt, frames and preview.

Keep every attempt. Record reviews and useful ranges in experiment notes; never replace a run with a newer generation. These media folders are ignored by Git. See the [working convention](../../../../../docs/workflow.md).
