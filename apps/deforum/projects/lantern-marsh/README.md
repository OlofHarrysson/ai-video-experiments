# Lantern marsh

A moonlit boardwalk, close reeds and copper lanterns, and a distant observatory. This study asks how extra render area helps a deliberate 3D camera move survive edge artifacts.

Current study: [three-second painted crop](exports/overscan-20260906T215334143141Z-overscan-24f/feedback-crop.mp4), with full/cropped comparisons in the experiment report. Preserve all full-size generations; crops are derived viewing choices.
