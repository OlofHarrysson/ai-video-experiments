# Sunlit Sketchbook

An opening-sequence homage to Shuvfx’s [Do It Big](https://shuvfx.myportfolio.com/do-it-big): a girl draws a unicorn in a sunlit room, the sketch becomes dimensional, and a cut reveals its imagined world. The first ten-second cut uses a forest; the revised storyboard uses a galaxy.

Olof approved this scope on 2026-11-10. First produce and review the still images, then animate them; music comes afterward. Use Fal through the connected plugin. Preserve the source attribution and distinguish generated homage images from original reference frames.

Current status: Olof finds the first cut too flat and asks for richer artwork and deliberate camera motion. [Room-v003](runs/room-v003/image.png), using an actual film frame for the room and a crop of our character for identity, is the recommended new opening candidate. [Revised storyboard](experiments/storyboard-v002.md): camera push into the room, angled pencil insert, transformation and galaxy reveal. Other new shots follow the room look review; no revised animation has run. The [first silent cut](exports/video-v001/sunlit-sketchbook-opening.mp4) and all generations remain preserved. Music comes later.
