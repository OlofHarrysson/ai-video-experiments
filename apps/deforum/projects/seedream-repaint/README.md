# Seedream per-frame repaint

E07 tests native Seedream 4 Edit on every independent depth-guide frame. The four-second sequence contains the preserved source anchor followed by 31 new edited images. Camera guides come from the existing DifforumGuideBuilder and DepthAnything V2 nodes; Seedream performs the repaint, with no SDXL sampling.

See [experiment and results](experiments/e07-native-edit.md) and the local [recipe](experiments/native_edit.py).
