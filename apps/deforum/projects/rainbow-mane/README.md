# Rainbow Mane

An original white cartoon character turns sideways; the rainbow mohawk becomes a horse's mane, the face becomes a horse's head, and a pullback reveals a white body. A 30–60 second short is the eventual intent. The first passage tests this transformation before committing to an ending.

Current cut: [v001 — 7.333-second feasibility passage](cuts/v001.md). [Watch in the reviewer](http://localhost:3028/rainbow-mane) · [MP4](exports/v001/p03b-full-body/through-0780/rife/preview.mp4).

The white/rainbow motif reaches a complete horse, but the separate head turn does not happen and the three semantic transitions are abrupt. Olof finds the style pretty good and the transformations too abrupt. This is a first test, not a finished story.

Latest rendered study: [four-second guided Krea morph](experiments/guided-repaint.md), following the profile-to-horse drawing Olof approved. [Watch the recommended painted test](exports/guided-morph-v001/guided-n040-a012/rife/preview.mp4) · [compare it with the drawing](http://localhost:3028/rainbow-mane-guided). Olof says it looks pretty good and restyles the input well. Assistant screening still identifies doubled contours and flatter treatment.

Next study: [graybox motion with a separate appearance reference](experiments/graybox-video.md). The neutral four-second guide and painted reference are prepared and checked. Seedance generation awaits Fal credit; no new paid job has been submitted.
