# Visual references

Four original user-supplied film screenshots are retained locally in `assets/`. [The manifest](manifest.json) records their original filenames, SHA-256 hashes, purpose and user timecodes. They are visual-style evidence only; this experiment does not upload them as model conditioning. Media files are ignored by Git.

The brief interprets their palette, halftone shading, rough black ink and layered printing into an original white character with a rainbow mohawk. No film file has been inspected, and the timecodes are not mapped to individual screenshots.
