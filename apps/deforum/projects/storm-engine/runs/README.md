# Run records

This production keeps its unique inference runs under `../exports/v001/runs/`, beside the preserved case trees. Each run retains the executed graph, submitted settings, history, source input where present, generated painting and hashes. Configurations and prefix inventories connect continuations without replacing earlier artwork.

Media and detailed run records are local and ignored by Git. The tracked [production notebook](../experiments/baseline.md) and [configurations](../experiments/configs) document the decisions and recipe. See the [storage policy](../../../../../docs/storage.md).
