# Exports

`v001/` contains the generated opening and directed continuations. Every case preserves its configuration, original paintings, run graphs and prefix lineage. The project’s `experiments/finish.py CASE pair|full|tail|check` maps source frames 0,12,24… to delivery frames 0,8,16… at 24 fps. A `through-NNNN/` directory selects a source boundary. The finisher preserves `rife/preview.mp4` with a brief final-painting hold and `rife-moving-tail/preview.mp4` with seven actual spatial warps. The selected sixty-second cut uses the clean `rife/` version to avoid a narrow edge seam in the final warps.

`motion-previews/` preserves camera-only studies of actual paintings. These do not predict new scenery or repainting. `media-review-v001/` contains the selected film’s reviewer. Generated artwork and videos are local and ignored by Git; the tracked recipe, decisions and cut records document them.
