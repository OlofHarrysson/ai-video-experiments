# Text-only and reference-conditioned generation

2026-09-08. First rebuild both original clips without cadence blending; preserve every anchor and original export. Then test both models using text-only generation and text plus an image. No partial img2img, RIFE, depth, optical flow, masks, image blending or added pixel noise in this round.

## Bounded test

Each arm is two seconds at 12 source fps, cadence 3, incrementing seeds. Eight anchors (including the opening) give seven later generations per arm. The direct twist is compressed from three seconds to two. Intermediates warp only the last anchor. Text-only anchors receive no image; they cannot inherit our pixel deformation. Reference anchors receive the warped previous generation. The opening is shared between the two arms of each model and generated by that model.

- Klein: same distilled 4B weights, four steps, Euler/Flux2 scheduler, CFG 1. Compare scene description alone with that same description plus a warped reference. A third reference arm uses a preservation instruction to test whether prompt wording reduces color drift. This changes the instruction, not the guidance setting.
- Krea: follow the ComfyUI style-reference template using INT8 Convrot Turbo, eight steps, Euler/simple, CFG 1 and ModelSamplingFlux (1.15/0.5). Both arms use this same checkpoint and a newly generated opening. Text-only has no LoRA; reference uses the documented style-reference LoRA at strength 1 and native image/text conditioning. This tests two supported recipes, not the isolated effect of adding a picture: the adapter also changes. Style conditioning is not a guarantee of layout preservation.

The earlier Krea audition used FP8 rather than INT8, so this is also not a controlled comparison of quantization. Exact model revisions and SHA-256 values are in [conditioning-models.json](conditioning-models.json). Prompt expansion stays off; the detailed natural-language scene prompt is preserved verbatim.

## Source evidence

- [ComfyUI Krea 2 guide](https://docs.comfy.org/tutorials/image/krea/krea-2): Turbo eight-step recipe, native style-reference template and required weights.
- [Adapter author's model card](https://huggingface.co/ostris/krea2_turbo_style_reference): trained on style pairs for one or two references; no trigger word required. Its older custom-node instructions differ from ComfyUI's current core-node template; this experiment follows the latter.
- [Krea prompting guide](https://github.com/krea-ai/krea-2/blob/main/docs/prompting.md): natural language, detailed prompts; no automatic prompt rewriting here.
- [Klein model card](https://huggingface.co/black-forest-labs/FLUX.2-klein-4B): native generation/editing, four-step distilled recipe, guidance 1.

Both previous recipes already used CFG 1. Increasing saturation is observed; excessive CFG is not established as its cause. Repeated editing, prompt interpretation and VAE round trips remain possible contributors. This round does not isolate all of them.

### Klein findings

- **Text-only:** matches the broad art concept, but redraws arch geometry, scale and explorer placement each anchor. A sampled frame introduces a white border. The model receives no warp information, so the spatial motion cannot survive a new anchor in a controlled way.
- **Reference + scene description:** substantially better layout and twist retention. Color shifts remain, including changes between cyan and yellow stone.
- **Reference + preservation instruction:** holds layout but still becomes strongly blue/cyan/yellow. Explicitly asking to retain exact saturation and brightness does not solve the drift in this run.
- **Codec diagnostic:** seven VAE encode/decode cycles without diffusion, warps or intermediate PNG encoding retain the original palette much more closely, although ink texture and contrast change. Whole-image mean HSV saturation: opening 0.4854, codec-only 0.5031, scene-reference final 0.6762, preservation-reference final 0.8341. The latter images include motion/content changes, so these are descriptive measurements, not a perfectly matched causal decomposition. Codec round trips alone do not reproduce the large drift.

### Krea findings

- **Text-only:** retains the named objects and broad illustration style, but changes arch contours and the explorer's scale and placement at each anchor. This is a sequence of independent redraws, not controlled continuation.
- **Text + style reference:** major changes begin on the first repaint: the arch reorganizes and the flame disappears. Later frames bring the flame back while holes multiply, orange and dark outlines fade, and the drawing becomes pale and porous. Some outcomes may be artistically interesting, but this recipe does not reliably carry the previous geometry or palette through the loop.
- The two arms intentionally differ by the trained style adapter and reference conditioning. Do not attribute every difference solely to the existence of an image input, or interpret this result as a verdict on all Krea workflows. The earlier partial-img2img result remains a separate, valid mechanism worth comparing.

## Recommendation

Continue with Klein's native reference mechanism for spatial control. A useful next hypothesis is to provide the original opening as a fixed color/style reference alongside the warped previous frame for geometry, using Klein's multiple-reference support. This is not implemented or validated here. Keep Krea available for art exploration; its style adapter did not solve controlled continuation in this test. Do not conclude that partial img2img is intrinsically the wrong animation process: conventional Deforum uses previous-image diffusion, while native reference editing is another mechanism to test.
