# Motion lab

Intent: find useful camera and repainting settings through short, adaptive video experiments using the preferred Seedream marsh reference.

Current cut: none selected.

## Experiments

- [E02 flat push](experiments/e02-flat-push.md): gentler feedback and a two-dimensional push-in.
- [E03 depth pullback](experiments/e03-depth-push.md): the same feedback settings with positive Z scene translation.
- [E04 sparse repaint](experiments/e04-sparse-repaint.md): change cadence to repaint every third frame.
- [E05 stronger repaint](experiments/e05-stronger-repaint.md): change denoise to .4.
- [E06 depth approach](experiments/e06-depth-approach.md): combine negative Z travel with sparse repainting.

Part of a ten-experiment session; the three-shot story, native Seedream repainting and independent SDXL redraw branches live in their own projects. Recipes were chosen after inspecting the first pair. All source frames, attempts and cut versions remain local.
