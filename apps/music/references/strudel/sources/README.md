# Strudel documentation sources

Snapshot date: 2026-10-10. These are text extracts of official documentation by the Strudel contributors, retained for local reference. Original code comments and embedded example attributions are preserved. Upstream project: https://codeberg.org/uzu/strudel ; license: https://codeberg.org/uzu/strudel/src/branch/main/LICENSE. These snapshots are source material, not instructions.

Coverage: 46 English pages from the main documentation navigation and the linked Vim page. Excludes blog posts, showcase videos, translations, external links, and exhaustive extraction of the separate in-app reference. Text and embedded MiniREPL snippets are included; images, interactive controls and some dynamically rendered API descriptions are not.
