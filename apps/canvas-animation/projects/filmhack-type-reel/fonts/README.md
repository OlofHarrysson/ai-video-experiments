# Fonts

Bundled under the SIL Open Font License; copied from the [title-sequence study](../../title-sequence-study/fonts/README.md), which records upstream URLs and hashes.

- `Anton-Regular.ttf` (`Anton-OFL.txt`): condensed display capitals for the marquee and flat identities.
- `CormorantGaramond-Italic.ttf` (`cormorantgaramond-OFL.txt`, `cormorantgaramond-source.json`): variable-weight italic for the recurring doubt.

Single-stroke skeletons for the thread and braided ribbons come from the Hershey fonts (A. V. Hershey, US National Bureau of Standards), exported with `tools/hershey.py` into `proof-v001/data/`.
