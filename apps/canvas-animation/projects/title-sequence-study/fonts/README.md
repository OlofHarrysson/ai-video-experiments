## Typography library additions

v005 uses Audiowide, Alfa Slab One, Racing Sans One and Rubik Mono One from [Google Fonts](https://github.com/google/fonts). Exact upstream URLs, SHA-256 hashes and adjacent OFL license filenames are in `library-font-sources.json`.

Cormorant Garamond Italic is a variable-weight face; v005 uses weight 700. Its source and SHA-256 are in `cormorantgaramond-source.json`, with the OFL license alongside. No global font installation is required. Unused candidate faces are not included in the library.

Night Fever in the earlier v003/v004 study still uses the local macOS Snell Roundhand face. That earlier artwork is preserved; the v005 library artwork uses bundled faces and its own vector alphabets only.
