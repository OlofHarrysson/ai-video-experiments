# Acid print reconstruction

Authorized 2026-10-10 after Olof approved the proposed second image-to-code study. No new persistent goal or paid generation. The generated reference was produced in the preceding discussion and is preserved independently here.

## Outcome and scope

Reconstruct the fluorescent print reference as editable, bitmap-independent lettering. Use the previously agreed sequence: flat geometry, early cut-section motion, then procedural ink. Make a short silent loop with medium-high rhythmic activity and no slow escalation or whole-card zoom. WILD HOURS remains placeholder copy.

Nine named glyph outlines, two diagonal sections per glyph, locally authored ink and negative-space decisions, deterministic procedural print texture. Keep the project’s existing modular study structure and local browser/FFmpeg export workflow. This is a style-and-motion experiment, not a film storyboard or a general font.

## Motion sketch

Eight seconds / 30 fps / 120 BPM. Diagonal shears, staggered letter offsets, row counter-motion and a final resolving phrase. Keep the two-row composition recognisable. The last frame returns to the opening configuration for a loop. No soundtrack in this visual test.

## Early findings

First still applied identical colour inversion to every lower letter section; this lost the reference’s local art direction. The D’s radial motif overwhelmed its silhouette. The second pass uses authored local ink patches and confines the fan to the corner. The first browser test caught a malformed W option in the letter selector; fixed before delivery. Second pass checks pass and an eight-second draft exists.

The first live renderer averaged 45 ms/frame in headless Chromium. Cropping the 18 cached plates to their glyph bounds is being tested to reduce compositing cost. This does not change the source geometry or import reference pixels.

## Selected checkpoint

Selected `output-phrase`, following one read-only Opus 5.5 critique of the second draft. Replaced uniform impulses with held configurations and a call-and-response phrase. Added crisp opposite-colour registration, independent fan/checker changes, sparse edge flecks, quieter pinholes and tonal ink variation. Retained the local wedges instead of making all letters share a decorative toothed seam.

The selected 240-frame, eight-second, 30 fps video decodes completely. Image-free repeatability, loop equality, zero-intensity restoration, controls, PNG/SVG downloads, mobile overflow and actual video playback all pass. Assistant inspected the final full still, clean geometry, comparison page, temporal samples, two nine-frame decoded transition windows and the decoded repeat boundary. Browser render-plus-readback averages 8.25 ms/frame. An earlier 0.02 ms timing did not flush Canvas commands and must not be used as a performance claim.

The code construction captures the graphic identity, but the generated reference retains richer organic print wear and some more varied fragments. Human motion preference is pending.
